# Trang giới thiệu bản thân — Phan Công Nhân

Trang web cá nhân bằng **Python Streamlit**, nội dung lấy từ CV.

## Chạy

```bash
pip install -r requirements.txt
streamlit run app.py
```

Mở `http://localhost:8501`.

## Nội dung

- Trang chủ: ảnh, giới thiệu, thông tin liên hệ, kỳ vọng công việc
- Kinh nghiệm làm việc
- Học vấn và bằng cấp
- Kỹ năng, chứng nhận
- Liên hệ và nút tải CV PDF

Sửa thông tin trong `PROFILE` ở `app.py`. Ảnh: `assets/avatar.png`. CV: `assets/cv_phan_cong_nhan.pdf`.
